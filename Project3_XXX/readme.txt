Features:
- Swing login and registration; account records are kept in data/users.txt.
- Text posts with optional image attachment; posts and copied images are kept under data/.
- Private text messages between local accounts; records are kept in data/messages.txt.
- Voice-message recording and playback through the JDK Java Sound API; WAV files are kept in data/voice/.
- Profile, friends, direct-message, and voice screens inspired by the supplied interface mockup.

No third-party application libraries are used. Voice messages are stored locally. This project does not
implement a real-time network voice call or multi-computer message server.

Run with NetBeans (JDK 26):
1. Open this folder as a Maven project.
2. Set Project3.MainApplication as the Main Class in Project Properties > Run.
3. Choose Run Project. The compiler plugin may be downloaded by Maven on the first build.
